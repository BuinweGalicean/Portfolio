# Buinwe Galicean Portfolio

This is a static portfolio website built with HTML, CSS, and JavaScript.

## Local preview

Open the site in a browser using a local web server:

python -m http.server 8000

Then visit:

http://localhost:8000

## Publish to GitHub Pages

1. Create a GitHub repository.
2. Push the project files to the repository.
3. In GitHub, go to Settings > Pages.
4. Set Source to Deploy from a branch.
5. Choose the main branch and root folder.
6. Save.

Your site will be published at:

https://your-username.github.io/your-repository-name/

## Publish to Netlify

1. Go to Netlify.
2. Drag and drop this folder into the dashboard.
3. Publish the site.
4. Netlify will give you a live URL.
